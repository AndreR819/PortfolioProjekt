# OS Sachsen – öffentliche vs. freie Trägerschaft

## Projektstruktur

### `data/`

Enthält die für die Analyse verwendeten Daten.

- `raw/`: Unveränderte Originaldaten aus den jeweiligen Quellen.
- `cleaned/`: Technisch bereinigte und für die Analyse vorbereitete Quelldaten.
- `processed/`: Im Verlauf der Analyse erzeugte oder weiterverarbeitete Datensätze.

### `notebooks/`

Jupyter Notebooks für Datenprüfung, explorative Analyse und Auswertung.

### `src/`

Wiederverwendbarer Python-Code.

### `outputs/`

Erzeugte Ergebnisse der Analyse, beispielsweise Abbildungen.
